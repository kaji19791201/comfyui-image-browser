# ComfyUI Image Browser (Kaji Fork)

## Description :mag:
This is a fork of [Flibens/comfyui-image-browser](https://github.com/Flibens/comfyui-image-browser) with minimal essential updates.

## Additional Features :sparkles:
- **Mobile Responsive Design:** Optimized gallery and modal viewer for phones and tablets.
- **Safe Clipboard Fallback:** Improved copy functionality (path, prompt, URL) for non-HTTPS and mobile environments.
